# #drones — Columbia Robotics

Open index.html with styles.css, script.js, and assets/ alongside it. No build step or external dependencies. The separate drones.html is a self-contained version of the same site.

Both Join the team and Support the build are direct mailto:mihir.garimella@columbia.edu links in index.html. Get involved in the header scrolls to that section.

The four build tabs work with mouse or keyboard; their descriptions share a grid cell to keep the page height stable. All descriptions are visible when JavaScript is disabled.

Edit copy in index.html, colors and layout in styles.css, and tab interaction in script.js. The supplied pilot photo is in assets/how-to-fly.webp. Confirm permission to publish it before launch.

The requested text cuts and replacements are applied. The rest of the layout and Columbia palette are preserved.
